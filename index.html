🗼 Towers / Sites Sheet

Main infrastructure master sheet — all site metadata linked by tower_id

🔴 Outages Sheet

Monthly dump — upload one file per month. Each upload is appended to the existing data, not replaced. Duplicate tickets (same TT #) are automatically removed.

🔔 Alarms Sheet

Monthly dump — upload one file per month. Each upload is appended to the existing data, not replaced. Duplicate tickets (same Ticket Id) are automatically removed.

🏗️ Civil PMR Sheet

Preventive Maintenance Rounds — Civil. Each visit is a row with inspection results and findings.

⚡ Electromechanical PMR Sheet

EM PMR — HVAC, rectifiers, batteries, earthing. Multiple visits per site over time.

🔋 Generator PMR Sheet

Generator Preventive Maintenance — diesel, fuel, oil, load test, runtime per visit.

📦 Assets Sheet

Equipment inventory — each row is one asset at a site. Sites can have many assets.

🦺 HSSE Events Sheet

Health, Safety, Security & Environment — Near Misses, T&V, incidents, property damage.

💰 CAPEX Sheet

Capital expenditure — projects, budgets, spend, contracts linked by tower_id. Any column structure accepted.
